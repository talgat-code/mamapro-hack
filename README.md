# Mama Pro — рабочее пространство команды

Помогаем родителям детей с особыми потребностями находить и выбирать коррекционных специалистов. Сейчас готовимся к сессии с родителем и выбору одного сценария для хакатона. Концепция, узкий сегмент, стек и окончательный объём MVP **не выбраны**; результатов интервью пока нет.

На 14 ноября 2026 в репозитории есть только рабочая документация. Приложения, manifest/lockfile и команд запуска, сборки или продуктовых тестов пока нет. Зависимости не установлены. Реализация — отдельная задача после выбора сценария.

## Команда

- **Алмаз:** продукт, интервью с родителем, приоритеты, проверка пути и питч.
- **Талгат и Тамер:** разработчики. Привычные инструменты и разделение задач ещё нужно согласовать; frontend/backend по именам не назначены.
- **Родитель:** подключается организатором, рассказывает свой опыт, проверяет предположения и проходит прототип. Его опыт не представляет автоматически все семьи.

## Как продолжить

1. Открыть [текущий фокус PLAN](docs/PLAN.md#текущий-фокус) и сверить местное время и обновления организатора. Организационные факты хранятся только в HACKATHON.
2. Алмаз проводит сессию по DISCOVERY. В репозиторий попадает необходимая обезличенная выжимка; исходные истории и контакты не коммитим.
3. На основании наблюдений выбрать один путь и обновить PRD/PLAN; последствия для реализации — TRD. До этого Must из PRD не означает согласования конкретного интерфейса.
4. Перед параллельной реализацией согласовать контракт, границы задач и одного владельца общих файлов/интеграции. Работать в отдельных ветках/checkout, для параллельных агентов на одной машине — в отдельных worktree. Git пока без коммитов: сначала нужен согласованный начальный коммит; worktree в этом запуске не создавались.
5. Для задачи: короткий план → изменение → релевантная проверка → просмотр diff вторым разработчиком или независимой сессией → небольшая интеграция → обновление PLAN.

Документацию проверяем по ссылкам и согласованности, а пробельные ошибки — существующей командой `git diff --check`. Продуктовые команды добавим сюда только после появления приложения и их фактического запуска.

## Следующие запросы агенту

> Вот заметки с родительской сессии: … Выдели наблюдения и гипотезы, обнови DISCOVERY/PRD/PLAN, покажи изменение scope. Не принимай новые предположения за факты.

> Выполни задачу … из PLAN. Прочитай относящиеся к ней требования и ограничения, реализуй в пределах задачи, проверь критерии и обнови состояние.
